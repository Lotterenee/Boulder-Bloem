## Summary
- Replaces the harness starter app: server.js now serves the five-page Dutch marketing site from public/ as static files.
- Clean URLs via express.static extensions option (/aanpak resolves to aanpak.html); unknown paths return 404 with the homepage as body.
- /healthz endpoint kept for Railway and the harness.
- railway.json watchPatterns now includes public/** so HTML edits trigger deploys.
- public/*.html: 122 em-dashes (U+2014) replaced with en-dashes (U+2013) per repo writing rule; no other content changes.

## What's new
- The Boulder Bloem site (index, aanpak, educatie, groen, subsidies) is live on the Railway environment instead of the "It works" starter page.
- Verified against docs/SPEC.md acceptance criteria: all pages 200 (clean and .html URLs), all section anchors resolve, Google Fonts links untouched, contact form is pure mailto to hallo@boulderbloem.nl, no starter references left, no em-dashes in the repo.

## Technical changes
- server.js: express.static on public/ with extensions:['html'] and maxAge 1h, /healthz JSON endpoint, 404 fallback sending index.html.
- package.json: renamed to boulder-bloem-website, version 0.1.0; package-lock.json added.
- railway.json: public/** added to build.watchPatterns; everything else untouched.
- No database, no backend form handling, no build step (per spec, out of scope).

## How to test
- Open the Railway environment URL: / and /aanpak, /educatie, /groen, /subsidies (with and without .html) all return 200.
- /healthz returns {"ok":true}; an unknown path returns HTTP 404.
- Click through the nav and anchor links (aanpak.html#kosten, index.html#contact, subsidies.html#scan).
- Submit the contact form on index.html#contact: it opens a prefilled mailto to hallo@boulderbloem.nl.
- git grep -lP "\xe2\x80\x94" returns nothing; git grep -il "harness-railway-starter" and git grep -l "It works" return nothing.
