## Summary
- Adds the five Dutch-language pages of the Boulder Bloem website (natural playgrounds) as static HTML under `public/`.
- Cleans up the duplicate copies that were manually uploaded to the repo root via the GitHub web UI: root and `public/` versions were byte-identical, so the merge nets out as a move into `public/`.
- Adds a short "This project" section to the README documenting where the site content lives.
- Sets the harness feature name to `website-paginas`.

## What's new
- Website pages: `index.html` (home), `aanpak.html`, `educatie.html`, `groen.html`, `subsidies.html` — complete with shared nav, footer, styling and a mailto-based subsidy-scan form.
- Note: the pages are content-only for now. The starter `server.js` does not serve `public/` yet; wiring that up is the next feature.

## Technical changes
- New directory `public/` with the five self-contained HTML files (inline CSS/JS, Google Fonts, inline SVG illustrations).
- Five root-level HTML duplicates removed; relative links between pages (`aanpak.html`, `groen.html`, …) keep working inside `public/`.
- `README.md`: added project section; `.harness-feature`: feature slug `website-paginas`.
- Starter files (`server.js`, `package.json`, `.gitignore`) and harness-managed files untouched.

## How to test
- After merge, open any of the five files under `public/` on the `dev` branch and check the pages render (e.g. open the raw file locally in a browser).
- Verify the repo root no longer contains loose `*.html` files.
- Internal nav links between the five pages resolve within the same directory.
